# 12. Glossary

> Draft for adviser review — flows and rules may change; see [README](README.md).

_Last updated: 23 October 2026._

| Term                                      | Meaning                                                                                                                                                                                                   |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ADVISER / WWR points**                  | The two columns of SLU's deduction matrix: grade points deducted by the faculty adviser and from the Weekly Work Report grade. Planned (L2).                                                              |
| **Approve / Return / Regard / Disregard** | The four faculty review actions on a weekly report. Approve and Regard make the hours count; Return sends it back with a note; Disregard removes an invalid submission.                                   |
| **Audit log**                             | An append-only record of security and data events (who, what, when, from which IP address). Cannot be edited or deleted.                                                                                  |
| **BSIT / BSCS / BMMA**                    | The three SAMCIS programs covered: Information Technology, Computer Science, Multimedia Arts.                                                                                                             |
| **CHED**                                  | Commission on Higher Education. Its **CMO No. 104, s. 2017** sets the Student Internship Program in the Philippines (SIPP).                                                                               |
| **CHED-SIAP**                             | CHED's program for international internships. Out of scope.                                                                                                                                               |
| **CMO**                                   | CHED Memorandum Order.                                                                                                                                                                                    |
| **Confirmed hours**                       | Hours from weekly reports that the faculty adviser Approved or Regarded. Only these count toward required hours.                                                                                          |
| **Coordinator**                           | The department internship coordinator (role: Department coordinator).                                                                                                                                     |
| **CPO**                                   | The SLU office that issues the Certificate of Attendance after the internship (as named in SLU's guidelines; full name to confirm with the adviser, Q18). Its certificate is tracked as status only (D7). |
| **Cron / daily job**                      | The scheduled task that runs once a day at 8:00 AM Manila for reminders, MOA warnings, data request reminders and the retention scan.                                                                     |
| **D2, D7, D1–D6**                         | Recorded project decisions. D2: no signed documents in IDSMS. D7: the checklist and certificates are status only. See [11](11-decisions-and-open-questions.md).                                           |
| **Deviation report**                      | A student's report of an absence, overtime or undertime for a date. Replaced by Leave & Time Requests in L1.                                                                                              |
| **DOLE**                                  | Department of Labor and Employment; one of the bodies mentioned in SLU's governance note.                                                                                                                 |
| **DP Orientation**                        | Data Privacy Orientation; one of the checklist items.                                                                                                                                                     |
| **DSAR**                                  | Data Subject Access Request: a person's request for a copy of their personal data under RA 10173. IDSMS gives the Super Admin 15 days.                                                                    |
| **DTR**                                   | Daily Time Record: the per-day time in/out and hours, kept in IDSMS inside each weekly report.                                                                                                            |
| **Endorsement letter**                    | The SLU letter endorsing a student to the host company. IDSMS generates it as a PDF (reference code EL-…) once all checklist items are approved.                                                          |
| **Endorsement gate**                      | The rule that blocks the endorsement letter until every pre-deployment checklist item is approved.                                                                                                        |
| **Excused**                               | A planned (L2) staff decision that removes an automatic deduction for HTE-attested documentation or circumstances beyond the intern's control.                                                            |
| **Export Center**                         | The Super Admin page for bulk Excel exports, data requests and file retention review.                                                                                                                     |
| **Final report cover**                    | The cover page PDF (reference code FC-…) for the final technical report; unlocks near the required hours.                                                                                                 |
| **Google Classroom**                      | SLU's learning platform; where students submit signed copies, medical and other sensitive documents.                                                                                                      |
| **HTE**                                   | Host Training Establishment: the company or organisation where the student interns.                                                                                                                       |
| **In-app notification**                   | A message shown under the bell icon in IDSMS.                                                                                                                                                             |
| **L1 / L2**                               | Workstream L parts. L1 (In progress): Leave & Time Requests, SLU hours rules and weekly report template. L2 (Planned): conduct and deductions.                                                            |
| **Leave**                                 | Approved time off, full or partial day, planned (anticipated) or emergency. Planned (L1).                                                                                                                 |
| **Manila time**                           | Asia/Manila (UTC+8). All deadlines and dates use it.                                                                                                                                                      |
| **MFA**                                   | Multi-factor authentication. Deferred; IDSMS uses a password re-check for sensitive actions.                                                                                                              |
| **MOA**                                   | Memorandum of Agreement between SLU and the HTE. Mandatory for all OJT. Tracked with lifecycle stages and validity dates.                                                                                 |
| **Monthly report / journal**              | A report per calendar month, built from approved weekly reports (reference code MR-…).                                                                                                                    |
| **NPC**                                   | National Privacy Commission, which enforces RA 10173.                                                                                                                                                     |
| **OJT**                                   | On-the-Job Training; the internship.                                                                                                                                                                      |
| **OT**                                    | Overtime: time worked outside the shift. Under SLU rules (L1) it counts only if approved and at least 30 minutes.                                                                                         |
| **Pending hours**                         | Hours in submitted weekly reports still waiting for faculty review. Shown, but not counted.                                                                                                               |
| **PH holidays**                           | Philippine national and regional holidays pre-loaded in the calendar.                                                                                                                                     |
| **PRD**                                   | Product Requirements Document (`docs/PRD.md`). Requirement IDs: FR- (functional) and NFR- (non-functional).                                                                                               |
| **Projected completion date**             | The date the student is expected to reach required hours, from confirmed hours and the schedule.                                                                                                          |
| **RA 10173**                              | Republic Act No. 10173, the Data Privacy Act of 2012.                                                                                                                                                     |
| **RBAC**                                  | Role-Based Access Control: what each role may see and do.                                                                                                                                                 |
| **Reference code**                        | A unique code printed on each document and submission: WR- (weekly), MR- (monthly), EL- (endorsement letter), FC- (final cover).                                                                          |
| **Re-authentication**                     | Entering your password again before a sensitive action.                                                                                                                                                   |
| **Retention review**                      | The 3-year rule: old files are flagged for the Super Admin to keep or delete; never deleted automatically.                                                                                                |
| **RLS**                                   | Row Level Security: database rules about which rows a database role may read or change. IDSMS uses default-deny RLS as a backstop.                                                                        |
| **SAMCIS**                                | School of Accountancy, Management, Computing and Information Studies, Saint Louis University.                                                                                                             |
| **Semester (active / archived)**          | One semester is active at a time. Archiving keeps all data.                                                                                                                                               |
| **Shift**                                 | A student's scheduled working hours (start, end, lunch break). Per-student shift is In progress (L1).                                                                                                     |
| **Signed URL**                            | A temporary (5-minute) link the server creates so an authorised user can download a private file.                                                                                                         |
| **SIPP**                                  | Student Internship Program in the Philippines (CHED CMO 104, s. 2017).                                                                                                                                    |
| **SLA**                                   | Service-level agreement: a time limit, such as 15 days for a DSAR.                                                                                                                                        |
| **Super Admin**                           | The system administrator role.                                                                                                                                                                            |
| **Supabase**                              | The cloud database and file storage used during development. Replaced by the lab computer in Phase 5.                                                                                                     |
| **Tardiness**                             | Arriving after the shift start. Under SLU rules (L1) it becomes undertime; there is no grace period.                                                                                                      |
| **UAT**                                   | User Acceptance Testing with real users, planned for Phase 5.                                                                                                                                             |
| **UT**                                    | Undertime: time short of the scheduled shift (late arrival, early leave, unplanned short day). Needs a request with a reason (L1).                                                                        |
| **Vercel**                                | The cloud hosting used during development.                                                                                                                                                                |
| **Work plan**                             | The student's planned internship tasks, approved by the coordinator; it unlocks the schedule.                                                                                                             |
| **Workstream**                            | A unit of Phase 4 work (A, B, C, D, E, F, G, H, L1, L2). See [10](10-roadmap-and-status.md).                                                                                                              |
| **WWR**                                   | Weekly Work Report: SLU's name for the weekly report.                                                                                                                                                     |
