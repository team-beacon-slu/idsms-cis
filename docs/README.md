## Rules for keeping this tidy

- **One topic, one document.** Before writing a new document, check this catalog; extend the existing one instead.
- **The code is the final word.** If a document disagrees with the code, fix the document.
- **Plans move when done.** A plan lives in `plans/` while it is being carried out, then moves to `archive/` with a line in [its index](archive/README.md).
- **Questions for the adviser go only in** [`ADVISER_QUESTIONS.md`](ADVISER_QUESTIONS.md). Other documents refer to them by number (for example "Q5").
- Update the "Last updated" line and this catalog when you add, move or retire a document.
